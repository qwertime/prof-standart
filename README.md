# ПРОФИ — обучение рабочим профессиям

Лендинг учебного центра «ПРОФИ»: официальное профессиональное обучение
рабочим специальностям с теорией, практикой и итоговой аттестацией.
Продолжительность программ — от двух недель.

## Сайт

**Публичная версия:** https://qwertime.github.io/prof-standart/

## Возможности

- подбор программ по рабочим профессиям;
- описание теоретического и практического обучения;
- информация о лицензии и аккредитации;
- блок гарантий;
- форма заявки на консультацию;
- адаптивная версия для компьютеров и телефонов.

Заявки из формы отправляются через FormSubmit на адрес владельца сайта.
При первом использовании получателю необходимо подтвердить адрес электронной
почты в письме от FormSubmit.

## Локальный запуск

Требуется Node.js версии 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Статическая сборка для GitHub Pages:

```bash
GITHUB_PAGES_BUILD=true npx next build
```
